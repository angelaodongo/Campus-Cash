# CampusCash 

A simple student budget planner built with Python.

## About

CampusCash is a beginner-friendly command-line program that helps students keep track of their budget and spending.

## Current Features

- Set a budget
- Add expenses
- Calculate total spending
- Calculate remaining budget

## Built With

- Python

## Project Status

Version 0.1 — In development

## Problem 

You are a university student trying to keep track of your money. 
You want a simple program that allows you to set a budget, record expenses, see how much you've spent, and know how much money you have left.

## Task v0.1

Write a Python program called campuscash.py that acts as a simple command-line student budget planner.

The program should allow the user to:

- Set a budget.
- Add expenses.
- View the expenses they have recorded.
- Calculate their total spending.
- See their remaining budget.
- Exit the program.

* NOTE * The program should continue displaying the menu until the user chooses to exit.
